Instalar Beekeeper Studio en Ubuntu

Dos caminos. El primero no instala nada y funciona siempre.

Opción A · AppImageRecomendada

Un solo archivo que se ejecuta directamente. No necesita permisos de administrador, no toca el sistema y se borra arrastrándolo a la papelera.

  1. Entra a beekeeperstudio.io/get y descarga el archivo .AppImage de Linux.
  2. Abre una terminal (Ctrl+Alt+T) y ve a la carpeta de descargas: 
    cd ~/Descargas    # o  cd ~/Downloads  si tu sistema está en inglés
  3. Dale permiso de ejecución: 
    chmod +x Beekeeper-Studio-*.AppImage
  4. Ejecútalo: 
    ./Beekeeper-Studio-*.AppImage

Si no abre y ves un error con libfuse: Ubuntu 22.04 y posteriores ya no traen FUSE 2. Instálalo una sola vez y vuelve a intentar:

sudo apt update
sudo apt install libfuse2

Si prefieres no instalar nada, también puedes ejecutarlo así:

./Beekeeper-Studio-*.AppImage --appimage-extract-and-run

Opción B · Paquete .deb

Se integra con el menú de aplicaciones y se actualiza con el sistema. Necesita permisos de administrador.

  1. Descarga el archivo .deb desde la misma página.
  2. Instálalo desde la terminal: 
    cd ~/Descargas
sudo apt install ./beekeeper-studio_*.deb
  3. Ábrelo desde el menú de aplicaciones buscando «Beekeeper».

También puedes hacer doble clic en el .deb y usar el instalador gráfico, pero apt install resuelve mejor las dependencias.

Abrir la base del curso

Da igual la opción que hayas elegido, el resto es idéntico:

  1. Descarga dvdrental.db desde la página del curso.
  2. Abre Beekeeper Studio.
  3. En el tipo de conexión elige SQLite.
  4. Pulsa Choose file y selecciona el archivo dvdrental.db.
  5. Connect. Deberías ver 15 tablas en el panel de la izquierda.

Comprobación rápida. Abre una pestaña de consulta con Ctrl+T, escribe esto y ejecuta con Ctrl+Enter:

SELECT COUNT(*) FROM film;

Si devuelve 1000, todo está en orden.

Si algo falla

Copia el mensaje de error exacto y pégalo en el chat de la sesión. Con el texto completo se resuelve en segundos; con «no me sirve» no.
