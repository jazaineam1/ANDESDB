Supabase sin misterio

Para esta sesión, Supabase es tres cosas

PostgreSQL en la nube

La base real vive en un servidor. No estamos usando un archivo local.

SQL Editor

El lugar donde pegamos y ejecutamos código SQL.

Table Editor

El lugar donde miramos tablas, columnas y filas de forma visual.

No es objetivo hoy: crear una app, usar Auth, programar JavaScript ni consumir la API.

Paso 1

Entra al dashboard y ubica tu organización

  1. Abre supabase.com/dashboard.
  2. Inicia sesión.
  3. Selecciona la organización del curso o la tuya.
  4. Busca el botón New project.
Frase para estudiantes: todavía no estamos dentro de una base; estamos en el panel donde se administran proyectos.
Paso 1 · DashboardANDESDB · Sesión 9
Paso 2

Crea el proyecto con nombre controlado

  1. Clic en New project.
  2. Nombre sugerido: andesdb-s9-equipo01.
  3. Escoge región cercana o la que indique el docente.
  4. Escribe y guarda la contraseña de la base.
  5. Clic en Create new project.
Importante: la contraseña de la base no es una PK ni una FK. Es una clave de acceso al servidor.
