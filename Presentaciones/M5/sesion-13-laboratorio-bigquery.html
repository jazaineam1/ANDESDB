Crear y consultar una tabla particionada

CREATE OR REPLACE TABLE curso.ventas_particionadas
PARTITION BY fecha AS
SELECT * FROM curso.ventas;
SELECT SUM(ingreso)
FROM curso.ventas_particionadas
WHERE fecha BETWEEN DATE '2026-01-01' AND DATE '2026-01-31';

Clusterizar organiza bloques por columnas que realmente filtras

CLUSTER BY categoria, cliente_id

Buen criterio

Patrón de acceso frecuente y selectivo.

Mal criterio

“Tiene muchos valores, entonces clusterizo”.

El orden importa: compara WHERE categoria=... con WHERE cliente_id=....
