¿Por qué separar en S8 y anidar ahora?

Operación

Si una línea se crea, modifica o valida independientemente, una tabla separada protege reglas y evita redundancia operacional.

Lectura analítica

Si casi siempre lees el pedido con todas sus líneas, anidar puede acercar la estructura al patrón de consulta y reducir JOINs.

No hay contradicción: el modelo se evalúa contra su carga de trabajo.

Una columna también puede contener estructura

SELECT STRUCT(42 AS pedido_id,
              [STRUCT('Ajiaco' AS plato, 2 AS cantidad),
               STRUCT('Jugo' AS plato, 1 AS cantidad)] AS lineas) AS pedido;

STRUCT

Agrupa campos con nombre.

ARRAY

Contiene una secuencia de valores o estructuras del mismo tipo.

BigQueryJerarquía explícita
34–44 min · hazlo conmigo

UNNEST convierte temporalmente un arreglo en filas

WITH pedidos AS (
  SELECT 42 AS pedido_id,
         [STRUCT('Ajiaco' AS plato,2 AS cantidad),
          STRUCT('Jugo' AS plato,1 AS cantidad)] AS lineas
)
SELECT pedido_id, l.plato, l.cantidad
FROM pedidos, UNNEST(lineas) AS l;
Predice antes de ejecutar: ¿cuántas filas aparecen? ¿Qué representa cada fila después de UNNEST?

La forma física también comunica decisiones

CSV

Plano, simple, interoperable. La jerarquía debe aplanarse.

JSON

Semiestructurado; conserva objetos y arreglos de forma natural.

Parquet

Columnar y tipado; eficiente para analítica y capaz de representar estructuras anidadas.

Elige formato para: intercambio humano simple · API/documento · lectura analítica por columnas.
