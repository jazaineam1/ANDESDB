Diseño y Gestión de Bases de Datos con SQL · una página para traducir el vocabulario del curso y del Workbench.

Grano

Qué representa exactamente una fila. Si cambia el grano, cambian conteos, promedios y joins.

Partición

Divide físicamente/lógicamente los datos por una clave para reducir lectura o distribuir carga. En BigQuery suele basarse en fecha.

Clustering

Organiza datos por columnas consultadas con frecuencia dentro de una partición. No reemplaza el filtro ni la partición.

UNNEST

Expande un arreglo anidado a filas. Antes: 1 fila = 1 entidad; después puede ser 1 fila = 1 elemento.

OLTP

Carga transaccional: muchas operaciones pequeñas, actuales, con integridad y baja latencia.

OLAP / analítica

Lectura y agregación de historia para comparar, resumir y decidir. Prioriza análisis sobre operación fila a fila.

ETL

Extraer → transformar → cargar. La transformación ocurre antes de llegar al almacén analítico final.

ELT

Extraer → cargar → transformar. Se aprovecha la capacidad del motor/plataforma destino para transformar.

Parquet

Formato columnar. Conviene cuando analítica lee pocas columnas de archivos grandes y quiere reducir bytes leídos.

CAP

En sistemas distribuidos, ayuda a razonar sobre consistencia, disponibilidad y tolerancia a particiones de red; no es una receta automática de producto.

PK / FK / CHECK

PK identifica; FK protege referencias; CHECK protege reglas de dominio. Se validan por comportamiento: aceptar lo válido y rechazar lo inválido.

Snapshot vs historial

Snapshot guarda el estado observado en un momento; historial conserva eventos. “Fila Cerrado” no implica “último estado Cerrado”.

Cadena de decisión: problema → evidencia → grano → modelo → integridad → representación → almacenamiento → analítica → validación → decisión.
