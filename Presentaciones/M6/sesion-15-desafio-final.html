Atención de incidentes urbanos

Una ciudad recibe reportes de alumbrado, ruido, huecos, basuras y semáforos. Cada caso cambia de estado; algunos eventos dejan trazas técnicas y algunos casos acumulan fotos, video o comentarios.

Observabilidad

Analítica

46–52 min · restricción del reto

No tienes que usar todas las tecnologías

Debes justificar

Relacional para operación, documento para estructura variable, objetos para bytes de archivos o una arquitectura híbrida si el acceso lo exige.

No puntúa

Nombrar Supabase, MongoDB, BigQuery o Azure sin explicar patrón de acceso, consistencia y fuente de verdad.

Metadatos ≠ archivo. Guardar MIME/tamaño/URL en una tabla no obliga a guardar allí los bytes de una foto o video.
