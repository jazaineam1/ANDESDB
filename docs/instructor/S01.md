# S01 · Cómo generamos valor con datos · guía docente

## Pregunta central
Diagnóstico + valor

## Riesgo didáctico principal
No explicar el pretest antes de recogerlo

## Evidencia mínima
cadena + pretest

## Ritmo
- Duración útil: **165 min**.
- Actividad cada 10–15 min.
- Conserva checkpoint y validación si vas tarde.
- Usa extensión solo si el núcleo está logrado.

## Cierre
Pide evidencia observable, no solo “¿se entendió?”.
