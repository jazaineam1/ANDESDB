# S01 · Guía docente

## Pregunta central
¿Cómo pasa un dato de existir a generar una decisión?

## Hilo conductor
- **Hereda:** Partimos de decisiones reales y del diagnóstico del grupo; todavía no asumimos que una herramienta produzca valor por sí sola.
- **Pregunta de hoy:** ¿Cómo pasa un dato de existir a generar una decisión?
- **Evidencia de salida:** Cadena evento → dato → almacenamiento → transformación → consumidor → decisión, más un diagnóstico inicial.
- **Puente:** Una decisión necesita respuestas verificables. En S2 aprendemos a preguntarle a una base de datos sin modificarla.

## Error esperable principal
confundir dato, herramienta y valor o asumir que todos los roles hacen lo mismo.

## Dónde probablemente se atascan
- Al traducir una pregunta de negocio a una unidad/grano de respuesta.
- Al confundir que algo ejecute con que responda correctamente.
- Al explicar la decisión con evidencia en lugar de repetir vocabulario.

## No avanzar hasta que…
El grupo pueda describir la cadena evento → dato → almacenamiento → transformación → consumidor → decisión.

## Evidencia mínima
pretest + cadena de valor.

## Si vas 15 minutos atrasado
Reduce ejemplos; conserva diagnóstico y roles.

## Si vas 15 minutos adelantado
Pide clasificar un caso nuevo y justificar el rol responsable.

## Intervención docente
Antes de mostrar una solución, pide una predicción o una explicación causal. Si el error es conceptual, conserva el error visible el tiempo suficiente para compararlo con el resultado correcto.

## Regla de cierre
Cierra con evidencia observable y una explicación breve. “¿Se entendió?” no cuenta como evaluación.
