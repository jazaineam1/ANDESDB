# S02 · Guía docente

## Pregunta central
¿Cómo convierto una pregunta sencilla en mi primera consulta?

## Hilo conductor
- **Hereda:** S1 dejó una decisión que necesita evidencia y una cadena para convertir datos en respuestas.
- **Pregunta de hoy:** ¿Cómo obtenemos una primera respuesta de una base sin alterar los datos?
- **Evidencia de salida:** SELECT, WHERE, ORDER BY y LIMIT usados para responder una pregunta concreta y validar el resultado.
- **Puente:** Listar filas ya no basta cuando el negocio pide comparar y resumir. S3 convierte filas en información agregada.

## Error esperable principal
copiar SELECT sin poder explicar SELECT/FROM/WHERE/ORDER BY/LIMIT.

## Dónde probablemente se atascan
- Al traducir una pregunta de negocio a una unidad/grano de respuesta.
- Al confundir que algo ejecute con que responda correctamente.
- Al explicar la decisión con evidencia en lugar de repetir vocabulario.

## No avanzar hasta que…
El grupo pueda traducir una pregunta a columnas, tabla, filtro, orden y límite.

## Evidencia mínima
checkpoint de las 3 películas PG más largas.

## Si vas 15 minutos atrasado
Omite comparaciones opcionales de motores; conserva práctica y checkpoint.

## Si vas 15 minutos adelantado
Cambia la pregunta sin nombrar las cláusulas y exige explicación.

## Intervención docente
Antes de mostrar una solución, pide una predicción o una explicación causal. Si el error es conceptual, conserva el error visible el tiempo suficiente para compararlo con el resultado correcto.

## Regla de cierre
Cierra con evidencia observable y una explicación breve. “¿Se entendió?” no cuenta como evaluación.
