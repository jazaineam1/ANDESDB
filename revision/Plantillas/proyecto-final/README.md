# Sesión 15 · Atención de incidentes urbanos

La herramienta principal es el **evaluador automático**: [`/ANDESDB/evaluador-s15.html`](/ANDESDB/evaluador-s15.html).

No necesitas preparar seis archivos para que el profesor los revise manualmente. Durante la sesión:

1. identifica el grano de `casos.csv`, `eventos.csv` y `evidencias.json`;
2. escribe un DDL mínimo que proteja reglas confirmadas;
3. ejecuta las cuatro consultas pedidas;
4. responde escenarios de arquitectura;
5. usa la retroalimentación automática para corregir;
6. registra el intento final en el LMS.

Los archivos de esta carpeta siguen disponibles como apoyo y para explorar los datos, pero **la evidencia evaluada vive en el intento automático**. Consulta `criterios.md` para conocer las pruebas y la rúbrica.
