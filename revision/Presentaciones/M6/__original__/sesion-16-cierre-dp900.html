MétodoEscenario antes que producto
40–52 min · conceptos centrales

Escenarios 1–3

1. Un archivo contiene filas/columnas con esquema fijo. ¿Estructurado, semiestructurado o no estructurado?
2. Una API entrega objetos con campos opcionales y arreglos. ¿Qué forma de dato describe mejor el caso?
3. Una tienda registra pedidos individuales y otra plataforma calcula tendencias mensuales. ¿Cuál es transaccional y cuál analítica?
Respuestas

1 estructurado · 2 semiestructurado · 3 pedidos = transaccional; tendencias = analítica.

Dominio 13 escenarios
52–64 min · relacional

Escenarios 4–6

4. Quieres impedir pedidos para clientes inexistentes. ¿Qué concepto relacional protege la regla?
5. Una tabla repite nombre del cliente en cada línea de pedido y las actualizaciones producen inconsistencias. ¿Qué principio debes revisar?
6. Necesitas una base SQL administrada sin administrar SO/VM. ¿Qué familia Azure compararías primero?
Respuestas

4 FOREIGN KEY · 5 normalización/dependencias · 6 Azure SQL Database o servicio relacional administrado equivalente según motor.

Escenarios 7–8

7. Debes guardar millones de imágenes y archivos Parquet históricos. ¿Blob, Files, Table o Cosmos?
8. Una aplicación necesita documentos distribuidos globalmente y baja latencia; cada entidad puede evolucionar de forma distinta. ¿Qué servicio reconocerías?
Respuestas

7 Azure Blob Storage · 8 Azure Cosmos DB, si los requisitos de acceso/distribución lo justifican.

Dominio 32 escenarios
89–103 min · analítica

Escenarios 9–11

9. Recibes un archivo al cierre de cada día y lo procesas en bloque. ¿Batch o streaming?
10. Necesitas procesar eventos casi en tiempo real a medida que llegan. ¿Batch o streaming?
11. Un equipo quiere ingeniería y analítica a escala con notebooks/Spark. ¿Qué servicios Microsoft debes reconocer?
Respuestas

9 batch · 10 streaming · 11 Azure Databricks y Microsoft Fabric según el escenario.

Dominio 43 escenarios
103–113 min · analítica y visualización

Escenarios 12–13

12. Una gerencia necesita un modelo semántico y dashboards interactivos sobre datos preparados. ¿Qué herramienta debes reconocer?
13. Una consulta analítica duplica ingreso al unir dos relaciones 1:N. ¿Qué debes revisar antes de cambiar de tecnología?
Respuestas

12 Power BI · 13 el grano y la multiplicación de filas; un servicio cloud distinto no corrige un JOIN conceptualmente incorrecto.
