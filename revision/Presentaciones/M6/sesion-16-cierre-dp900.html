Devolución del desafío

Tres errores de alto valor que S15 puso a prueba

1 · Último evento vs. fila con ese estado

Filtrar WHERE estado='Cerrado' no demuestra que Cerrado sea el último evento. Primero decides pertenencia; después calculas.

2 · Una restricción debe comportarse bien

PK, FK, NOT NULL y CHECK no se validan por “verse correctos”: deben aceptar lo válido y rechazar lo inválido.

3 · No mezclar granos

Un JOIN 1:N, un promedio por evento o repetir el costo de envío por línea cambia la unidad que estás contando.

SQL ArenaConsulta que debe sobrevivir casos borde; no significa “juego”, significa depurar con evidencia.
DDL MutationUna versión defectuosa del esquema sirve para hacer visible qué restricción falta.
Boss TransferUn caso nuevo cambia el contexto: mide transferencia, no memorización del caso anterior.

Vocabulario nuevo · concepto conocido

El hueco DP-900 más grande cabe en dos familias

Familia relacional Azure SQL
  • Azure SQL Database: base SQL administrada PaaS.
  • Managed Instance: PaaS con alta compatibilidad a nivel de instancia.
  • SQL Server on Azure VM: control de VM y sistema operativo.
  • Azure Database for PostgreSQL/MySQL: motores open source administrados.
Storage y NoSQL
  • Blob: objetos como imágenes, CSV o Parquet.
  • Files: archivos compartidos mediante protocolos de archivos.
  • Table: clave/atributo NoSQL simple.
  • Cosmos DB: NoSQL distribuido; patrón de acceso, partición y API importan.
No memorices “JSON → Cosmos” ni “SQL → Azure SQL Database”. Primero identifica requisito, carga y patrón de acceso.

Un mismo puntaje puede esconder problemas distintos

C · Concepto

No podría explicar la diferencia aunque quitáramos todos los nombres Azure.

Acción: vuelve al concepto y construye un ejemplo propio.

T · Transferencia

Entiendo el problema, pero no recuerdo cómo se llama la familia o servicio en Azure.

Acción: mapa concepto → servicio + documentación oficial.

L · Lectura

Conozco concepto y servicio, pero ignoré una condición crítica del escenario.

Acción: subraya requisito, restricción y palabra que cambia la decisión.
