# S16 · Guía docente · cierre + preparación DP-900

## Propósito
S16 cierra el diplomado y convierte la segunda mitad en una preparación útil para **presentar DP-900**, sin volver a enseñar un catálogo de servicios Azure ni repetir la evaluación S15.

La transición docente es:

> Ya aprendiste a razonar problemas de datos. Ahora necesitas entender qué evalúa DP-900, cómo es la experiencia real del examen y cómo practicar con las herramientas oficiales.

## Principios
1. **S15 ya es la evaluación integradora.** S16 no crea otro examen custom.
2. **El repaso del curso se limita a ~60 min.**
3. **No reenseñar Azure servicio por servicio.** El detalle queda en el Cheat Sheet y Microsoft Learn.
4. **Fuente oficial vigente:** Study Guide en inglés, skills measured as of **July 21, 2026**.
5. **No prometer un número fijo ni tipos exactos de preguntas.** Microsoft no los publica de antemano.
6. **Practice Assessment + Exam Sandbox son las referencias prácticas.**
7. **La encuesta institucional ocurre después del cierre.**
8. **El temporizador es el componente compartido de S15 v7.**

## Presupuesto docente · 180 minutos = 165 útiles + 15 de pausa

### 0–60 · Cierre del diplomado
- **0–8 · Apertura + recorrido:** S2→S15 como una sola progresión.
- **8–20 · SQL + pensamiento SQL:** repertorio, orden lógico y grano; no reenseñar sintaxis.
- **20–35 · Modelo + integridad + almacenamiento + analítica:** recuperar decisiones, no detalles.
- **35–48 · S15 como evidencia:** qué integró el Workbench.
- **48–60 · Un caso puente:** separar OLTP, objetos, analítica histórica y streaming.

### 60–95 · Qué es DP-900 y cómo es hoy
- **60–70 · DP-900 empieza:** requisito → concepto → opción Microsoft → descartar distractores.
- **70–80 · Blueprint vigente:** cuatro dominios y pesos.
- **80–95 · Experiencia actual del examen:** 45 min, 65 min de seat time, 700+, nivel Beginner, proctorizado, español disponible, registro.

### 95–110 · Pausa
El componente compartido muestra el timer de 15 minutos.

### 110–165 · Interfaz + práctica oficial
- **110–125 · Exam Sandbox:** interfaz, reloj, preguntas restantes, marcar para revisión y navegación.
- **125–160 · Practice Assessment:** **8–10 preguntas oficiales**, razonadas en conjunto.
- **160–165 · Debrief:** identificar dominio débil y convertir errores en una regla de estudio.

### 165–180 · Voucher + recursos + cierre
- cuenta Microsoft personal;

- Practice Assessment → Microsoft Learn → Sandbox → agendar;

## Blueprint oficial vigente
Skills measured as of **July 21, 2026**:
- **Describe core data concepts: 25–30%**
- **Identify considerations for relational data on Azure: 20–25%**
- **Describe considerations for working with non-relational data on Azure: 15–20%**
- **Describe an analytics workload on Azure: 25–30%**

La sesión muestra estos cuatro dominios para orientar el estudio. **No intenta impartir cada servicio Azure en clase**; el mapa detallado está en el Cheat Sheet y en Microsoft Learn.

## Cómo es el examen actualmente
Según la página oficial de Microsoft Learn:
- nivel **Beginner**;
- **45 minutos** para completar la evaluación;
- **65 minutos de seat duration** para un examen Fundamentals;
- **700 o más** para aprobar;
- examen **proctorizado**;
- español aparece entre los idiomas disponibles;
- puede contener componentes interactivos;
- Microsoft no publica de antemano un número fijo de preguntas ni una lista cerrada de tipos de pregunta.

Para familiarizarse con la interfaz y los tipos que se pueden encontrar, usar **Exam Sandbox**.

## Practice Assessment
Usar **8–10 preguntas oficiales**, según ritmo. No copiar el banco a la presentación.

Por cada pregunta:
1. identificar el dominio;
2. localizar el requisito decisivo;
3. descartar opciones incompatibles;
4. responder;
5. leer la explicación oficial;
6. convertir el error en una regla de estudio.

La evaluación de práctica sirve para aproximarse a estilo, redacción y dificultad; **no contiene las preguntas reales ni representa necesariamente la longitud o complejidad exactas del examen**.

## Registro y voucher
- Microsoft recomienda registrar el examen con una **cuenta Microsoft personal (MSA)** para conservar el historial aunque se pierda acceso a una cuenta laboral/institucional.
- DP-900 se puede programar por **Pearson VUE**; estudiantes/docentes pueden ver **Certiport** cuando corresponda.
- No inventar vencimiento del voucher. Confirmar entrega, código y fecha por el canal oficial de Colsubsidio/Uniandes.
- Si el primer intento no se aprueba, Microsoft permite repetirlo después de **24 horas**; para intentos posteriores aplican otros periodos de espera según la política vigente.
