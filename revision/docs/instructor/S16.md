# S16 · Guía docente · cierre + preparación DP-900

## Propósito
S16 cierra el diplomado sin repetir S15 y usa la segunda mitad para que el estudiante entienda **qué evalúa DP-900, cómo es hoy el examen, qué formatos puede encontrar, cómo practicar y cómo usar el voucher**.

La transición docente es:

> Ya aprendiste a razonar problemas de datos. Ahora necesitas reconocer cómo Microsoft organiza esos conceptos y cómo se presenta el examen.

## Principios
1. **S15 ya es la evaluación integradora.** S16 no crea otro examen custom.
2. **El repaso del curso se limita a ~60 min.**
3. **El bloque final se compacta:** no hay diapositivas administrativas separadas para Sandbox, registro y Cheat Sheet.
4. **Fuente del blueprint:** Study Guide en inglés, skills measured as of **July 21, 2026**.
5. **No prometer un número fijo de preguntas.** Microsoft indica que el número puede variar.
6. **No prometer tipos exactos para DP-900.** El Exam Sandbox muestra formatos que podrían aparecer.
7. **DP-900 es Fundamentals: Microsoft Learn NO está disponible dentro del examen.**
8. **Practice Assessment + Exam Sandbox son las referencias prácticas.**
9. **La encuesta institucional ocurre después del cierre.**
10. **El temporizador es el componente compartido de S15 v7.**

## Blueprint oficial vigente
Skills measured as of **July 21, 2026**:
- **Describe core data concepts: 25–30%**
- **Identify considerations for relational data on Azure: 20–25%**
- **Describe considerations for working with non-relational data on Azure: 15–20%**
- **Describe an analytics workload on Azure: 25–30%**

La sesión orienta el estudio; no intenta impartir nuevamente un catálogo completo de Azure.

## Cómo es el examen actualmente
Según Microsoft Learn:
- nivel **Beginner**;
- **45 minutos** de exam duration;
- **65 minutos** de seat duration para Fundamentals;
- **700 o más** para aprobar en escala 1–1000; **700 no equivale necesariamente a 70%**;
- español está disponible para DP-900;
- se presenta en un entorno seguro/proctorizado;
- se programa mediante **Pearson VUE** o Certiport cuando corresponda;
- Microsoft no publica un número exacto de preguntas. Su guía general de certificaciones dice que normalmente hay **40–60**, mientras material reciente específico de Fundamentals menciona con frecuencia **35–50**; enseñar por tanto que el número es variable;
- Microsoft no publica de antemano los tipos exactos de pregunta que tendrá un intento;
- el Exam Sandbox muestra ejemplos como **multiple choice, drag & drop, build list, hot area, case study y active screen**;
- en exámenes Fundamentals **no está disponible Microsoft Learn durante el examen**;
- se permiten pausas no programadas, pero el reloj sigue corriendo y no se puede volver a preguntas ya vistas después de iniciar la pausa.

## Practice Assessment
Usar **8–10 preguntas oficiales**, según ritmo. No copiar el banco a la presentación.

Por cada pregunta:
1. identificar el dominio;
2. localizar el requisito decisivo;
3. descartar opciones incompatibles;
4. responder;
5. leer la explicación oficial;
6. convertir el error en una regla de estudio.

El Practice Assessment aproxima estilo, redacción y dificultad; no contiene las preguntas reales ni garantiza la longitud, complejidad o los formatos del examen.

## Registro, voucher y reintentos
- Microsoft recomienda registrar el examen con una **cuenta Microsoft personal (MSA)**.
- Confirmar por el canal oficial de Colsubsidio/Uniandes **entrega, código y vencimiento** del voucher.
- DP-900 se programa por **Pearson VUE**; estudiantes/docentes pueden ver Certiport cuando corresponda.
- Si no se aprueba el primer intento, Microsoft exige esperar **24 horas** para el segundo.
- Después, hay **14 días** entre intentos posteriores, con máximo **5 intentos en 12 meses**.
